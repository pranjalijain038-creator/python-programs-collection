# Python Programs Collection

## About the Project

This project contains three beginner-friendly Python programs created to practise basic programming concepts.

## Programs Included

### 1. Factorial Calculator

Calculates the factorial of a non-negative integer using a loop and handles invalid input.

### 2. Fibonacci Series Generator

Generates a specified number of Fibonacci sequence terms.

### 3. Structure-to-Dictionary Conversion

Demonstrates how to convert a Python dataclass into a dictionary using the `asdict()` function.

## Technologies Used

* Python
* Python Dataclasses

## How to Run

Make sure Python is installed on your computer.

Open the terminal in the project folder and run each program:

```
python factorial.py

python fibonacci.py

python structure_to_dictionary.py
```

## Learning Outcomes

* Understanding loops and conditional statements.
* Handling invalid input.
* Generating a Fibonacci sequence.
* Working with dataclasses and dictionaries.
